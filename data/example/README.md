# Exported menu

Generated by ImGui Menu Editor. Needs Dear ImGui 1.92 or newer.

| File | What it is |
|---|---|
| `menu_generated.h` | Your menu: `menu::State` (all values), `LoadFonts`, `LoadImages`, `ApplyStyle` / `ApplyTheme(i)`, `Render` |
| `mm_widgets.h/.cpp` | Custom widgets (toggles, keybinds, sidebar tabs, animations). Add the `.cpp` to your build |
| `assets/` | Fonts (Font Awesome icons included) and images |
| `example/` | A small GLFW + OpenGL3 app that shows the menu |

## Adding it to your project

```cpp
#include "menu_generated.h"

// once, after ImGui::CreateContext() and your backend's Init:
menu::LoadFonts("path/to/assets");
menu::LoadImages("path/to/assets", MyLoadTexture); // ImTextureID (*)(const char* path, int* w, int* h)
menu::ApplyStyle();

static menu::State state;

// every frame, between ImGui::NewFrame() and ImGui::Render():
if (menu_visible) menu::Render(state);

// read values anywhere:
if (state.aim_enabled) { /* ... */ }
if (state.cfg_save)    { /* button was clicked this frame */ }
```

Keybinds are stored as `ImGuiKey` values; check them with `ImGui::IsKeyDown((ImGuiKey)state.aim_key)`.
Switch themes at runtime with `menu::ApplyTheme(index)`; the names are listed in `menu::theme_names`.

## Trying the example

```bash
cd example
cmake -B build -DIMGUI_DIR=/path/to/imgui
cmake --build build
./build/menu_preview
```
